# 仿生蝴蝶机器人 · Biomimetic Butterfly Robot

一个**翼展约 70 cm 的遥控仿生扑翼蝴蝶**。两只舵机分别驱动左右翅膀，飞控板根据遥控信号实时生成余弦扑翼波形，可以控制扑翼频率、幅度、升降和转向。

本仓库开源了完整的制作资料：**飞控板原理图与 PCB 生产文件、Arduino 飞控程序、3D 打印结构件、材料清单**，以及一个基于 STM32 + NRF24L01 的自制遥控器工程。

---

## ✨ 特性

- **双舵机直驱扑翼**：左右翅各由一只 GDW 1906 舵机驱动，结构简单、易于复刻
- **余弦扑翼波形**：半个扑翼周期分成 18 步按 `y = A·cos(ωt) + h` 输出，动作平滑
- **实时可调**：通过遥控器调节扑翼频率、扑翼幅度（三挡）、升降、左右差速转向，并可在线微调舵机中位
- **自制飞控板**：ATmega328P 最小系统 + 5V 稳压，兼容 Arduino，2S 锂电池直接供电
- **结构件可 3D 打印**：提供 SketchUp 源文件（`.skp`）和可直接切片的 `.stl`

## 🔌 飞控板

原理图见 [`document.pdf`](./document.pdf)，使用嘉立创 EDA 设计。

| 部分 | 器件 | 说明 |
|------|------|------|
| 主控 | ATmega328P-AU，16 MHz 晶振 | 与 Arduino Uno / Nano 相同芯片 |
| 电源 | AMS1117-5.0 + SS16 二极管 | 2S 锂电池（VIN）降压到 5 V |
| 接收机接口 | XH2.54-6P（U4） | VIN / GND / **D6（PPM 信号）** |
| 舵机接口 | XH2.54-6P（U5） | **A0、A1** 分别输出两路舵机信号，舵机由 VIN 供电 |
| 下载口 | 1×4P（P2） | MISO / MOSI / SCK / RESET，用于 ISP 烧录 |
| 串口 | 1×4P（P1） | VCC / TX / RX / GND，可接 USB-TTL 调试或下载 |
| 其他 | 复位按键、电源指示 LED | — |

**PCB 下单**：将 `PCB生产文件Gerber_扑翼机飞控8.5v.zip` 上传到嘉立创下单即可，流程参考 [嘉立创 EDA 文档 · PCB 下单](https://docs.lceda.cn/cn/PCB/Order-PCB)。BOM 中已附立创商城编号，可直接配合坐标文件使用 SMT 贴片服务。

> 💡 新芯片需要先用 USBasp 等 ISP 下载器通过 P2 烧录 Arduino Bootloader（或直接用 ISP 下载程序），之后可以通过串口下载。

## 💻 飞控程序

### 编译与下载

1. 安装 [Arduino IDE](https://www.arduino.cc/en/software)（使用自带的 `Servo` 库，无需额外依赖）
2. 打开 `蝴蝶Arduino代码/butterfly_FS1906/butterfly_FS1906.ino`
3. 开发板选择 **Arduino Uno**（或 Nano，ATmega328P 16 MHz）
4. 通过串口（P1）或 ISP（P2）下载程序

### 遥控通道映射

程序从 D6 读取接收机的 PPM 信号（同步脉冲 > 5000 µs 之后依次读取 8 个通道），映射关系如下：

| 通道 | 变量 | 功能 | 取值范围 |
|------|------|------|----------|
| CH1 | `cs` | **差速转向**：左右翅幅度差 | −100 ~ +100（±5 以内死区） |
| CH2 | `sj` | **升降**：调整两翅扑动中心位置 | −200 ~ +200（±5 以内死区） |
| CH3 | `ys` | **扑翼频率 / 启停**：每步延时 | 10000 ~ 6000 µs |
| CH5 | `c5` | A0 舵机中位微调 | 0 ~ 200 µs |
| CH6 | `c6` | A1 舵机中位微调 | 0 ~ 200 µs |
| CH7 | `fd` | **扑翼幅度**（三段开关） | 400 / 500 / 600 µs |

> ⚠️ 程序用到了第 7 通道（三段开关）。如果你的遥控器/接收机输出的通道数不足 7 个，需要先扩展通道数，或者修改代码中 `fd` 的取值方式。

### 控制原理

- **待机**：CH3 在最低位（`ys > 9500`）时不扑翼，翅膀停在中位，此时仍可用 CH2 调整翅膀角度
- **扑翼**：推起 CH3 后进入扑翼。半个周期分成 18 步（0°、10° … 170°），往返共 36 步，两只舵机的脉宽分别为：

  ```
  A0 = (中位0 + 升降) + (幅度 − 差速) · cos(θ)
  A1 = (中位1 − 升降) − (幅度 + 差速) · cos(θ)
  ```

  两只舵机安装方向相反，因此公式符号相反，实现左右翅对称扑动。

- **频率**：一个完整周期约 36 × `ys`，对应约 **2.9 ~ 4.6 Hz**（未计入程序运算耗时）
- **转向**：CH1 让一侧幅度变大、另一侧变小，产生左右推力差
- **舵机中位**：代码中默认 A0 = 1410 µs、A1 = 1490 µs，可按实际装配修改 `servoC_0` / `servoC_1`，或者在飞行时用 CH5/CH6 旋钮微调

### 串口调试

把 `setup()` 中的 `Serial.begin(115200);` 和 `loop()` 末尾的 `Serial.println(...)` 取消注释，就能在串口监视器中查看各个控制量。注意串口打印会拖慢扑翼节奏，仅建议调试时使用。

## 🛠️ 组装要点

1. 3D 打印舵机支架、舵机臂、后翅支架、多功能支架和电池支架（舵机支架、舵机臂均有新旧两版，推荐使用新版）
2. 把两只 1906 舵机固定在舵机支架上，舵机臂连接碳纤维翅杆
3. 用碳纤维杆搭出前后翅骨架，蒙上 P31N 风筝布
4. 飞控板接线：接收机 → U4（D6 为 PPM 信号），两只舵机 → U5（A0 / A1），2S 电池 → VIN
5. **先不装翅膀**通电测试：CH3 最低位时舵机应回中，再根据实际情况调整中位与扑动方向
6. 装上翅膀，从低频、小幅度开始试飞

## 🎮 自制遥控器（STM32，可选）

`stm32-遥控器工程/` 是一个基于 **STM32F103C8 + NRF24L01** 的自制遥控器：

- 摇杆和电池电压由 ADC + DMA 采集：PA0 电池电压、PA1 ROLL、PA2 PITCH、PB0 YAW、PB1 THROTTLE
- 遥控数据按 MSP 协议（`$M<`）打包，通过 NRF24L01 无线发送；也可通过串口（115200）发给上位机
- 使用 Keil MDK 打开 `代码/MDK-ARM/Project.uvprojx` 编译，J-Link / ST-Link 下载
- 原理图与封装库为 Altium Designer 工程，位于 `原理图/遥控器/`

> 注：目前蝴蝶飞控板通过 PPM 接收富斯接收机的信号，并未板载 NRF24L01。若要配合这套自制遥控器使用，需要在接收端增加 NRF24L01 并修改飞控程序的数据读取部分。
